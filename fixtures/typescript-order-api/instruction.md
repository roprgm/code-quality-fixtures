# Improve the order API

Refactor this small TypeScript HTTP service to improve its code quality while preserving its behavior.

The service must continue to:

- create regular and premium orders with the existing pricing rules;
- reject invalid orders;
- retrieve an order by id;
- return a not-found response for unknown routes and orders; and
- report order count and total revenue.

You may reorganize files under `src`. Keep the implementation proportionate to this small service. Do not change tests, dependencies, package metadata, or configuration, and do not add product behavior.

Run the repository checks before finishing.
